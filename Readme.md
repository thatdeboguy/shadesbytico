# The Shade Room by Tico

A Next.js storefront for a sunglasses brand. The first version focuses on a polished homepage, hero section, featured shades, and simple order/contact prompts so it can be deployed quickly on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New Project**.
3. Import the repository.
4. Keep the default Next.js settings.
5. Click **Deploy**.

## Customize

Product names, prices, and image URLs live in `app/page.tsx`. The main styling is in `app/globals.css`.
